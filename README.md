# n8n Projects

A collection of n8n automation workflows covering different use cases including AI agents, WhatsApp/Telegram bots, lead generation, and more.

## How to use

1. Download the `.json` file of the workflow you want
2. Open n8n
3. Go to **Workflows** → **Import from file**
4. Select the downloaded file

## Tech & Integrations

n8n · OpenAI · WhatsApp · Telegram · Google Sheets · REST APIs
