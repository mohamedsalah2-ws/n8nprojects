## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/mohamedsalah2-ws/n8nprojects.git
```

### 2. Open n8n

Run your n8n instance or access your n8n cloud account.

### 3. Import a Workflow

1. Open your n8n dashboard.
2. Select **Import from File**.
3. Choose the desired `.json` workflow.
4. Review the workflow nodes and connections.

### 4. Configure Credentials

Set up the required API credentials, integrations, and environment variables.

Depending on the workflow, you may need:
- AI provider API keys.
- Messaging platform credentials.
- Webhook URLs.
- Database or vector storage credentials.
- MCP configuration.

### 5. Test & Activate

Execute the workflow, verify its behavior, and activate it when everything is configured correctly.
